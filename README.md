# 人工智能训练师三级 · 四川备考学习平台

面向零基础学员的备考学习平台，将课程学习、题库练习、模拟考试和 DeepSeek 学情分析整合在一起，并提供 Windows 一键部署包。

## 主要功能

- **全程学习**：6 个阶段、24 节备考概览，配套 12 单元、48 节 Python 基础小课，从运行第一行代码逐步进入数据处理。
- **先讲再练**：48 个完整示范与逐行解释、96 个编程练习、48 道理解题，提供分步提示、错误解释和可停止的浏览器运行环境；保留原有 41 题作为补充。
- **分层数据练习**：3 份模拟小表及 UCI Iris、Wine 数据集，附下载、字段说明、任务与来源许可。
- **题库与实操**：900 道理论题、40 项实操任务，支持错题复习。
- **模拟考试**：理论、技能与入门诊断，支持计时、保存答案和成绩记录。
- **AI 学情分析**：接入自己的 DeepSeek API Key，分析薄弱知识点并生成后续学习建议。
- **安全保护**：账号权限、接口限流、敏感字段加密、加密审计与最小权限数据库配置。

## 一键部署

在本仓库 [Releases](https://github.com/xiaofan-tongxue/ai-trainer-platform/releases/latest) 下载 `AITrainer-Windows-OneClick.zip`，完整解压后双击 **一键安装.bat**。

适用于 **Windows 10/11 64 位**，建议预留至少 **8 GB** 空间。安装包包含 Java 21、MySQL 8.4、Python 3.13、pip、完整课程题库和素材，自动配置独立环境、数据库、端口及随机管理员初始密码。首次登录必须修改密码。

DeepSeek API Key 需在管理后台填写。运行环境可离线安装；DeepSeek 和网页 Python 首次加载仍需联网。全新安装包不包含原学员数据或密钥。

详见 [一键部署指南](deploy/windows/README.md)。

版本提示：当前源码已增加 48 节 Python 小课；现有 `v1.0.0` 安装包发布于本次课程扩充之前，不包含这些更新。源码课程说明见 [Python 基础学习指南](docs/PYTHON_FOUNDATIONS.md)。

## 源码与开发

主要技术：Java、MySQL、原生 HTML/CSS/JavaScript；AI 分析通过服务端调用 DeepSeek。

模型素材使用 **Git LFS**。克隆前安装 Git LFS，克隆后运行：

```text
git lfs install
git lfs pull
```

源码不包含个人数据库、运行密钥、缓存或安装环境。开发构建可使用 `build.ps1`；首次配置数据库和安全迁移请按 [部署说明](DEPLOY.md) 执行。已有加密数据库不要重新导入种子或覆盖密钥。
