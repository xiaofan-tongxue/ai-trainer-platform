# 零基础到三级的全局覆盖审查

本审查回答的是“平台是否把备考所需能力组织成可学习、可练习、可验收的路径”，不回答“某个学员必然通过”。国家职业技能标准和评价机构批次通知才是最终依据；平台没有取得科教兴川历次完整三级试卷，也没有真实考后样本来校准通过率。

## 覆盖结论

平台当前按六个考试训练领域组织内容，理论与技能分开训练，保留了 60 分双科合格、理论至少 90 分钟、技能至少 120 分钟的训练约束。`data/competency_matrix.json` 将每个领域连接到知识主题、题库数量、实操任务数量和可交付证据；`tools/audit-readiness.py` 会检查映射是否漂移。

## 对零基础的要求

零基础学员不能只刷900道题。建议先完成48节Python小课，再完成电脑文件、表格、数据字典和统计基础；之后按业务数据→智能训练→系统交互→培训指导顺序学习。每个领域至少做两次不同任务，提交代码/步骤、运行结果、解释和自检记录，再进入限时模拟。

平台的可通过证据门槛是：近30天至少3次有效理论整卷和2次四领域技能整卷，技能作答至少120分钟且四项均完成审阅；学情页会把不足显示为“暂不估计”。即使达到该门槛，结果仍是未经过四川考后数据校准的规则估计。

## 仍需学员或机构确认的内容

1. 本批次报名资格、评价机构、考试日期、软件/库版本、联网规则、素材与成果提交格式。
2. 科教兴川本批次实际题型、任务数量、评分细则与是否允许使用特定工具。
3. 学员能否在不看参考答案的情况下从空目录复现四类实操，并解释每个指标和异常分支。
4. 真实考试前至少做一次与考场软件、文件路径、保存和提交方式一致的演练。

## 运行审查

```text
python tools/audit-readiness.py
python tools/python-course/verify.py
node tools/check-frontend.js
```

第一条检查题库标签、领域权重、实操四领域和学习目标；后两条分别检查Python示例/答案和前端脚本。它们都是内容与软件一致性检查，不能替代评价机构发布的考务确认或正式测评。
