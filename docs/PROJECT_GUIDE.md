# 人工智能训练师三级 · 四川备考学习平台

在原有 Java 8 + MySQL 5.7 + 原生前端项目上升级。默认评价机构为四川省科教兴川促进会，串联零基础起步、专项训练、限时模拟、错题复测和 DeepSeek 学情分析。

## 开始使用

新电脑优先使用[Windows一键部署包](../dist/AITrainer-Windows-OneClick.zip)：解压后双击“一键安装.bat”，自动配置Java、独立MySQL、Python/pip、课程题库和加密账号。详细说明见[一键部署指南](../deploy/windows/README.md)。这是全新安装包，不包含当前电脑的学员记录或密钥。

本机数据库和题库已经存在，安全迁移已完成，直接运行 `start.bat`，或依次运行 `build.ps1`、`run.ps1`。访问 [学习首页](http://localhost:19001/index.html)。已有账号首次登录后必须更新密码；服务默认仅本机访问，需使用初始化密钥库时的Windows账号启动。

已有数据库升级时**不要重新导入 seed.sql**。安全版本启动不自动变更表结构；新实例/旧版本升级按[安全部署手册](security/06-deployment.md)先完成备份与维护迁移。运行数据库使用独立最小权限账号。

安全版本已实现字段加密、密码派生、会话与CSRF保护、API限流和加密审计。完整整改报告、测试证据与等保差距见[安全材料包](security/README.md)。生产网络防护、老旧组件升级、定级与正式测评仍需完成，当前不宣称通过等保。

```powershell
.\build.ps1
.\run.ps1
```

1. 在首页填写每天可用时间和预计考试日期，未定可留空。
2. 做20分钟入门诊断，再进入“全程学习”。
3. 依次完成6阶段24节备考概览，基础阶段配套48节Python小课：概念、示范、逐行解释、理解题、跟做、独立练习和复盘。路线约136小时包含练习与返工，不是机构规定培训学时，也不承诺固定时间学会。
4. 先完成48节Python基础小课，再按需要使用保留的41个补充练习、6个代码实验、13章参考资料、900道理论题及40道实操任务补强。新增5份可下载数据用于分层练习，详见[Python基础学习指南](PYTHON_FOUNDATIONS.md)。专项题支持领域、题型和错题筛选。
5. 分别完成90分钟理论模拟和120分钟技能模拟；服务器保存试卷、计时和答案，刷新可继续。
6. 在“学情与通过评估”生成DeepSeek报告，按具体行动与七天计划复测薄弱点。

## 考试与资料依据

国家2021年正式标准：理论和技能均为百分制，各60分合格；理论不少于90分钟，技能不少于120分钟。

| 领域 | 理论 | 技能 |
|---|---:|---:|
| 职业道德 | 5% | 0% |
| 基础知识 | 10% | 0% |
| 业务分析 | 20% | 25% |
| 智能训练 | 30% | 35% |
| 智能系统设计 | 30% | 35% |
| 培训与指导 | 5% | 5% |

已检索[科教兴川2023公告](https://www.kjxc.org/news/442.html)、[2024公告](https://kjxc.org/news/447.html)、[2025公告](https://www.kjxc.org/news/2240.html)，均指向2021年国家标准。机构网站直连失败，公告信息由官网搜索索引核验；未获取完整历次三级试卷。来源、日期、核查方式和适用范围记录于 `data/curriculum.json`，界面“考务依据”可查看。

原900题、40任务属于上海相关公开备考整理，原作者说明答案为个人理解。原13章参考资料来自CN-AI-Trainer。平台100题理论卷、4任务技能卷是按国标覆盖的训练设计，190题上海模式保留为补充练习，均不声称为科教兴川真题。自动知识标签可能有偏差；正式题型、软件、报名资格和材料要求须核对具体批次。

## DeepSeek

管理员进入“管理后台 → AI判题配置”，填写官方地址、模型和API Key，保存后可测试连接。密钥输入留空会保留原值，接口只返回是否配置，普通用户和公开设置均无法读取密钥。

也可在启动前设置环境变量（优先于数据库配置）：

```powershell
$env:DEEPSEEK_API_KEY = '你的密钥'
$env:DEEPSEEK_MODEL = 'deepseek-flash'
.\run.ps1
```

默认官方 `https://api.deepseek.com/chat/completions`，兼容已有 `/v1/chat/completions`。模型可修改；旧 `deepseek-chat` / `deepseek-reasoner` 配置在此版本映射为 `deepseek-flash`。以[DeepSeek官方文档](https://api-docs.deepseek.com/zh-cn/)为准。

学情报告仅发送汇总统计、基础水平和可用学习时间，不发送姓名、邮箱、用户ID或原始答案。Python反馈、技能审阅按功能需要发送对应题目、代码/文字和报告输出，AI不会替代真实运行验证。

接口设置连接/读取超时、并发上限、临时错误重试，校验JSON、评分范围、七天计划和每日时间。零基础学员在前四课通过之前，七天计划固定遵循电脑、Python、数据表的先修顺序，未完成任务可顺延。连接、余额或格式错误会明确显示；学情报告回退本地建议，技能整卷保留待审阅状态，可接着审阅。相同证据复用成功报告，报告生成间隔至少60秒。

## 通过可能性怎样计算

必须有近30天至少3次国标覆盖理论模拟和2次完整技能模拟。理论至少作答60秒；技能至少120秒且四项均完成DeepSeek审阅。诊断、上海补充卷、速交空卷、旧无计时记录、关键词分和课程自测不参与概率计算。诊断可以影响领域学习建议。

规则为 `p = 1 / (1 + exp(-(均分-60)/尺度))`；理论尺度 `max(8,标准差+5)`，技能尺度 `max(12,标准差+8)`，双科结果为两科p相乘。敏感性范围分别扰动理论均分±5、技能均分±10。没有足够证据显示“待测评”，而不是0%或AI猜出的百分比。

**这是未经考后数据校准的规则估计。**区间不是统计置信区间，独立性假设、重复题目、非独立作答、跨地区试卷与AI审阅误差会影响结果，不能保证正式考试合格。DeepSeek解释该估计并给建议，不覆盖数值或伪造历年通过率。

## 主要文件

- `data/curriculum.json`：课程、48道自测与考务证据。
- `service/ExamService.java`：服务器考试状态与判分；`ReadinessEngine.java`：可解释估计。
- `service/LearningService.java`：档案、课程进度、汇总、报告和缓存；`DeepSeekClient.java`：服务端适配。
- `db/Migrations.java`：增量学习表；`web/ApiHandler.java`：接口及用户权限。
- `webapp/js/learning.js`：首页、学习路线、学情、考务；`webapp/js/exam.js`：四种模拟流程。

当前保留原项目本地部署架构，账号与会话机制已安全加固。多实例部署需把进程内会话、限流及考试互斥改为共享存储/数据库锁；本版本按单个服务进程运行。Python实验首次加载依赖外网，浏览器运行环境与考场软件可能不同；生产执行域隔离与严格CSP见安全整改台账。
