# 网络安全等级保护差距分析与测评证据矩阵

## 1. 定级与适用性

运营单位、系统负责人、生产资产边界、用户规模、服务对象、业务中断影响和数据泄露影响：均待运营单位确认。等级：待定。不得以职业技能“三级”或存在AI功能直接推定等保三级。按GB/T22240开展定级，依据最终等级及实际部署形态核对GB/T22239通用要求和适用扩展要求，并按GB/T28448组织测评取证。

本矩阵按二级/三级常见控制域组织准备工作，不代替完整标准逐项判定。二级与三级的具体强度、适用对象和测评项不同；“已验证”仅指本次证据覆盖的应用控制，绝不自动推出该控制域整体符合。
