# 网站安全评估、整改与复测报告

报告编号：AIT-SEC-20260914 ｜ 状态：应用层整改复测完成，部署与合规差距未关闭

## 1. 评估对象与方法

对象为本地源码、前端、数据库访问层、账号与会话、DeepSeek适配器、文件下载、部署脚本、依赖JAR和历史项目备份。动态目标为 `http://127.0.0.1:19001`；使用临时普通用户和管理员测试夹具，结束后清理。已有用户数据先加密备份再迁移；迁移前在独立测试库验证。未执行公网主机扫描、破坏性负载测试、真实学员数据导出或付费模型调用。

方法包括源码人工审查、认证/权限/输入/路径负向用例、HTTP动态验证、数据库字段抽检与全列约束检查、密码学行为测试、隔离迁移恢复演练和业务回归。依赖检查确认版本及生命周期风险，未获得完整商业漏洞库或全量CVE关联结果。这里的覆盖范围不等于“已发现全部漏洞”。空表的密文检查只证明检查条件未发现明文，不证明存在历史样本；真实迁移样本另由隔离库测试验证。
