# Python 学习记录持久保存修复

2026-09-24。旧版48小课只把记录放在 sessionStorage，关闭标签页或退出登录就可能丢失。当前版本通过 `/api/learning/python-progress` 保存到登录账号对应的数据库，提供已读、历史练习完成标记与最近学习位置。复习时改代码或答错不会删除过去的完成记录。

只同步学习标记，不上传代码草稿。草稿仍需下载保存。顶部会提示保存结果；网络失败时保持页面打开并重试。仍留在旧标签页中的记录自动补存，已经清除且未曾上传的记录无法恢复，学员可以手动重新标记已读。

## 更新已有源码部署

停止应用进程，更新源码后运行 `build.ps1`，再启动应用并刷新页面。无需重新导入数据库、重新安装 MySQL 或更换密钥。使用 `v1.1.1` 一键包的独立实例时，拉取源码不会自动更新那个实例；旧发布包不包含此次修复。

## 存储与边界

复用既有 `lesson_progress` 表，ID 使用 `python:` 前缀，状态为 `python_completed` 或 `python_bookmark`。每个学习步骤独立写入并幂等合并，旧标签页提交不会覆盖其他标签页完成的步骤。书签沿用既有受保护 score 字段保存课程序号并加密。无需DDL或新增数据库权限。接口只使用认证会话中的用户ID，不接受客户端指定账号。

这些标记仅用于个人学习导航，不证明服务器执行过代码，状态不会计入24节备考概览的 passed 数量，也不参与考试通过率估计。接口沿用认证、CSRF、限流及参数化SQL保护。
