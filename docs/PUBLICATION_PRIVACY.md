# 公开发布前隐私检查

公开仓库只包含项目源码、教学资料、配置示例和部署说明。运行数据库、学员记录、真实 API Key、DPAPI 密钥、日志、备份与本机安装目录通过 `.gitignore` 排除。环境变量示例只使用占位值，安装包为全新安装，管理员密码在安装时随机生成。

提交使用 GitHub 的 `users.noreply.github.com` 隐私邮箱。旧仓库保留为私有归档，公开仓库使用独立的脱敏提交历史。

后续提交前执行：

```text
git add <准备提交的文件>
python tools/check-publication.py
```

检查脚本扫描暂存区，发现常见 Token、私钥、个人 Windows 用户目录、实例文件或非隐私提交邮箱时返回非零退出码，报告仅显示文件名和规则，不回显匹配值。它用于阻止误上传，不会修改运行中的密钥，也不代替人工复核；普通格式密码、未知 Token 和二进制文档内部信息仍需专项检查。

发布 ZIP 必须另外核对内部文件及嵌套应用包，确保不含已有实例、账号数据库、日志和密钥。不要把已有实例目录直接压缩后发布。若实际密钥曾对外暴露，应在服务商后台撤销并重新生成；删除文件或改写提交不等于撤销密钥。
