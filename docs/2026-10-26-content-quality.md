# 题库与实操持续优化记录

日期：2026-10-26。接续[首轮全局审查](2026-10-26-readiness-review.md)。本文件描述当前源码状态；旧 Release 不会随源码自动更新。

## 学员现在可以怎样使用

先完成基础课程，再从“实操训练”进入任务。每项任务给出先修课、第一步、操作顺序、验收清单和常见报错排查。代码任务可下载参考脚本，把脚本与该题素材放在同一文件夹执行；带子目录的素材保持目录结构。先跟做，再关闭参考独立重做，并记录实际输出。

本次保留已有课程和学员记录，继续使用24节概览、20节衔接课、48节Python小课。更新通过版本化资料叠加到现有数据库读取结果，不需要重新导入种子数据。

## 题库解析与争议处理

- 原900题中有300题没有解析；现已补充300份概念说明、逐选项分析、小例子与主题阅读入口。
- 解析经 DeepSeek 辅助生成、结构检查和重点抽查，不宣称逐题经过专家验证。抽查发现的机械复述、随机划分泛化、合同效力推断等已人工编辑修正或补充限制。
- 151题存在答案分歧、条件不充分、法律依据待核对或工具版本不明确等问题，标记“待复核”。其余题也不因此被证明正确。
- 原资料答案保留，不直接采用模型建议替换答案。待复核题可作辨析练习，但不进入新模拟卷，不形成新的错题判定，不计入领域掌握度。练习尝试仍保存。
- 已保存的整卷如包含这些题，其成绩和作答保留，能力评估会说明排除原因。旧卷提交时也补充解析和内容提示。
- 解析按题型、题干、选项与原答案的指纹匹配，不依赖数据库自增编号。题目经管理员修改后，不会误套旧解析。答案、解析和包含答案信息的指纹不会在作答前接口返回。

自动领域标签沿用原题库，可能存在分类偏差。当前可供抽卷的数量为749题，仍满足六领域训练权重；这只是抽题资格，不是已获官方审定的题量。

## 实操修正

40项实操均补充学习指引。20项包含代码，20项为方案/培训/指导等文字任务。修订15份完整脚本，其余5项保留经运行验证的示例。

| 问题 | 修正或边界 |
|---|---|
| 标准化、缺失填补与类别编码在数据划分前拟合 | 建模示例改为先划分，再用训练集拟合预处理；验证集用于方案选择，最终测试集用于最后评价 |
| 分类目标被当成有连续距离的类别编号回归 | 年龄区间例改为分类演示，并注明与原题存在冲突 |
| 可选改进代码强制依赖未安装的 XGBoost | 修订示例使用 scikit-learn 完成对应模型，不因额外依赖中断主流程 |
| ONNX示例固定使用不存在的 onnx/ 目录 | 路径与实际下载素材对应，保持本题子目录结构 |
| Pillow已移除 Image.ANTIALIAS | 使用 Image.Resampling.LANCZOS |
| softmax输出被称为准确率 | 明确为模型置信度；单图推理不能证明测试准确率 |
| 数据目标含义与泄漏风险 | 保留回归目标原单位；四项问卷均值只称代理目标，其构成项从输入中删除；不把相关性解释为因果 |
| 手机打开长代码后页面撑宽 | 约束实操主列宽度，代码块内部滚动，标题和按钮可以换行 |

## DeepSeek配置与学情

本机已验证官方接口连接并更新加密设置。密钥未写入源码、解析数据、文档或部署包。其他安装仍应在管理后台填写自己的密钥。

本轮调用仅用于公开练习题的辅助审校，没有发送学员成绩或身份资料。学情分析继续依据服务端筛选后的记录生成建议；通过可能性使用公开规则估计，尚无科教兴川真实考后样本校准。版本标识在 2026-10-26 为 `heuristic-v4-content-quality`。2026-11-11 起，技能成绩排除规则改为 `heuristic-v5-practical-conflicts`：仍排除未修订题，并排除没有本次修订标记的 2.1.5、2.2.3 旧卷。课程自查、单次文本审阅和运行成功均不构成正式考试通过保证。
